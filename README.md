# Not That Awk — interactive prototype

Revamped, clickable prototype of the Not That Awk app (Figma: "FTE Portfolio").

Run locally:

    python3 -m http.server 8080   # then open http://localhost:8080

Press `P` to toggle the presenter sidebar (jump to any of the ~35 screens). `?s=<screen>&id=<story>&slide=<n>` deep-links.
Illustrations are raster crops from the Figma frames (`assets/`); swap in SVG exports for sharper art.
All copy is placeholder and needs expert review. Awkie replies are scripted, not AI.
